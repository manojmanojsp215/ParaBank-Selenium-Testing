# ParaBank Selenium Testing Project

## Project Description
This project automates the testing of the ParaBank banking website using Selenium WebDriver and Java.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven
- Eclipse IDE

## Test Scenarios
- Login page testing
- Valid and invalid login testing
- XPath locator testing

## Framework
This project uses Selenium WebDriver with TestNG for automated testing.
